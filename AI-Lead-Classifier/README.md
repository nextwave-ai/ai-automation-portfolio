# AI Lead Qualification & Scoring Automation

This workflow automatically evaluates incoming leads using OpenAI, assigns qualification scores, updates Google Sheets, and sends Telegram notifications for high-value prospects.

## Features

- AI lead scoring
- OpenAI integration
- Google Sheets automation
- Telegram notifications
- Lead qualification system

## Tech Stack

- n8n
- OpenAI API
- Google Sheets
- Telegram Bot
