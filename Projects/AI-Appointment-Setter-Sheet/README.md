# AI Appointment Setter Sheet

## Status

⚙️ **Runnable Workflow — tested end-to-end.** `Workflow.json` is included in this folder and can be imported directly into n8n. Verified with live execution: correctly generates a complete, placeholder-free outreach email and writes it back to the matching row.

---

## Overview

AI Appointment Setter Sheet is an n8n workflow that automatically drafts a personalized outreach email for every new lead added to a Google Sheet, and writes the finished email back into the sheet — ready to review and send.

Unlike a generic "AI writes everything" approach, this workflow separates the variable part (the email body, written by AI based on the lead's company and industry) from the fixed part (the sender's name, title, company, and contact info, which is set once and never generated by AI). This is a deliberate design decision that guarantees the signature can never contain unfilled template placeholders.

---

## Business Problem

Businesses collecting leads in a spreadsheet often need to send a first outreach email to every new contact. Doing this manually is repetitive, and naively asking an AI model to "write the whole email including a signature" risks the AI leaving placeholder text like [Your Name] or [Your Company] unfilled in the final output.

---

## Solution

This workflow watches a Google Sheet for new rows. For each new lead, it normalizes the lead's data, generates only the email body with AI (explicitly instructed never to include a signature or placeholder brackets), then deterministically appends a fixed signature block built from values set once in a dedicated "Sender Info" node — never from the AI. The complete, ready-to-send email is written back into the same row.

---

## Key Features

- Google Sheets Trigger (polls for new rows every minute)
- Row Data Normalization
- AI-generated email body only — no AI-generated signature
- Deterministic, fixed sender signature (name, title, company, email, phone)
- Placeholder Detection & Rejection on the AI body (falls back to a safe generic message if brackets are detected)
- Match-by-Email Update Logic (prevents duplicate rows on re-run)

---

## Workflow

1. Google Sheets Trigger polls the sheet every minute for newly added rows.
2. Normalize Row Data maps the raw columns (Name, Email, Company, Industry, Priority) into clean variables.
3. Sender Info provides the fixed, human-edited sender identity — name, title, company, email, phone. This node's output never comes from AI.
4. Generate Email Body sends the lead's company and industry to OpenAI, which writes only the body text of the email — explicitly instructed to never include a signature or template brackets.
5. Compose Final Email checks the AI body for leftover placeholder brackets (falling back to a safe generic message if found), then appends the fixed signature from Sender Info and assembles the final subject plus body.
6. Append or Update Row writes the finished email and a "Ready to Send" status back into the matching row, identified by email.

## Workflow Architecture

Google Sheets Trigger (poll: every minute, event: row added) → Normalize Row Data → Sender Info (fixed values, not AI-generated) → Generate Email Body (AI, body only) → OpenAI Chat Model → Compose Final Email (rejects placeholders, appends fixed signature) → Append or Update Row (matched by Email)

---

## Reliability: AI output is never trusted directly

The Compose Final Email code node scans the AI-generated body for leftover template brackets (e.g. [Your Name], [Company]) using a regex check, and replaces the entire body with a safe generic fallback if any are found. More importantly, the signature is never AI-generated at all — it's built entirely from fixed values set once in the Sender Info node. This architectural choice is what eliminates the placeholder bug seen in earlier versions of this workflow, rather than just detecting and patching it after the fact.

## Setup

1. Create a Google Sheet with headers: Name, Email, Company, Industry, Priority, OutreachEmail, Status
2. Import Workflow.json into n8n.
3. Connect your own Google Sheets credentials to both the Google Sheets Trigger and Append or Update Row nodes, and point them at your sheet.
4. Connect your own OpenAI credentials to the OpenAI Chat Model node.
5. Open the Sender Info (edit these values) node and replace the sample values (senderName, senderTitle, senderCompany, senderEmail, senderPhone) with your real sender identity.
6. Activate the workflow (or trigger manually via Execute workflow for testing).
7. Add a new row with lead data to test — the OutreachEmail and Status columns should populate automatically.

---

## Error Handling

- If the AI's response is empty or still contains template placeholder brackets, the body falls back to a safe generic message instead of writing broken text to the sheet.
- The signature is deterministic and sourced from a dedicated node rather than AI, so it can never be incomplete or contain unfilled brackets.
- Matching on email (rather than row position) means re-running the workflow on the same lead updates the existing row instead of creating a duplicate.

---

## Security

No credentials, tokens, or secrets are included in this repository. Configure your own Google Sheets and OpenAI credentials in n8n before running. The sample sender identity included in Workflow.json (Alex Morgan, hello@nextwave-ai-demo.example) is placeholder demo data, not a real contact — replace it with your own before using this workflow for real outreach.

---

## Limitations

- Trigger is poll-based (checks every minute), not instant.
- This workflow drafts emails only — it does not send them. A human reviews and sends manually, or a Gmail/SMTP send step would need to be added.
- No deduplication beyond the email match — if the same email appears in two different rows, only one will reliably get updated.
- Industry-specific personalization depends entirely on the Industry column being filled in accurately.
