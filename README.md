# AI Automation Portfolio

A collection of production-ready AI automation workflows built with **n8n**, **OpenAI**, **Google Workspace**, **Slack**, **Telegram**, and REST APIs.

This repository showcases business automation solutions designed to eliminate repetitive manual work, improve operational efficiency, and accelerate sales and customer workflows using AI.
